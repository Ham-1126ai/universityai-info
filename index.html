UniversityAI

大学の資料と学習記録を、自分のPCで整理する個人用の学習支援プロジェクトです。大学やGoogleの公式サービスではありません。

機能プライバシーポリシー利用条件

できること

  • Google Classroomの課題、教材、お知らせ、取得できる本人の提出状態や点数の整理。
  • 許可されたGoogle Drive資料の学習用コピー。元資料は変更しません。
  • WebClassの科目・教材一覧の確認。資料本体・課題詳細・提出状態・成績の完全自動取得は未対応です。
  • 保存した資料を参照し、AIとの対話で要約、演習、復習、提出前確認。

課題の提出やテストの送信は本人が行います。このサイトに学習データや認証情報は掲載しません。

プライバシーポリシー

取得と用途

本人が許可したGoogleアカウントから、クラス、課題、期限、投稿、教材、添付資料、本人の提出状態や点数など、APIで取得できる学習情報を読み取ります。用途は本人の学習、課題整理、資料検索、復習、提出前確認です。権限はGoogleの認証画面で確認できます。

保存と共有

取得データは本人のPCに保存し、Google Drive for desktopで同期する設定では本人のGoogle Driveにも保存します。認証トークンとWebClassの登録資格情報はWindowsの暗号化機能でPC内に保管し、プロジェクトの同期対象には含めません。Googleアカウントのパスワードは保存しません。

AIに資料を読ませる操作では、そのサービスへ内容が送信される場合があります。所属機関の規則と利用するAIサービスのデータ取扱設定を確認して利用します。取得情報の販売や広告目的の利用は行いません。

保持と削除

資料・学習記録は本人が削除するまで保持します。現在の自動運用では実行ログは90日、自動バックアップは7世代を目安に整理し、手動バックアップは別管理です。Googleアカウントの接続管理でアクセス権を取り消せます。取り消しても保存済みデータは自動削除されません。削除する場合はPC、同期先、バックアップをそれぞれ確認してください。

Googleデータ

Google APIから受け取った情報の利用と他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

お問い合わせ

運営者本人が使用する個人用プロジェクトです。認証に関する問い合わせ先はGoogleの同意画面に表示されるユーザーサポートメールです。

利用条件

本人がアクセス権を持つ情報を学習目的で利用します。取得元の利用規約、著作権、所属機関の規則を守ってください。一般向けのアカウント登録やサービス提供は行っていません。

取得情報には遅延や未取得の項目があり、AIの説明や採点には誤りが含まれる可能性があります。締切・提出の成否・試験情報は元のサービスでも確認してください。満点や点数は保証しません。課題提出、テスト開始・回答送信、フォームの最終送信は自動実行しません。
